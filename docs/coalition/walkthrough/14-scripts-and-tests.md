# Разбор 14 — Скрипты и тесты

> [Разбор 00 — Оглавление](README.md) · предыдущая: [Разбор 13 — Тестовые агенты](13-test-agents.md)
> Файлы: `scripts/compare_coalitions.py`, `scripts/train_coalition.py`, `experiments/coalition_stage1.yaml`, `experiments/coalition_bandit.json`, `tests/test_coalition_policy.py`, `tests/test_coalition_stage2.py`, `tests/test_coalition_stage3.py`.

## Зачем нужны

Код политики сам по себе ничего не доказывает. Нужно:

1. **проверить, что он правильный** — тесты;
2. **измерить, насколько он хорош** — сравнение с другими политиками;
3. **обучить обучаемую часть** — скрипт обучения;
4. **запускать одной командой** — YAML-эксперимент.

## 1. Эксперимент в YAML: `experiments/coalition_stage1.yaml`

Готовый запуск через стандартный запускатель среды:

```yaml
name: coalition_stage1
horizon: 64
seeds: [0, 1, 2]
agents: {count: 12, default: {impl: "social_market_env.baselines.agents:CartelAgent"}}
coalitions:
  policy:
    impl: "coalition_policy:AdaptiveCoalitionPolicy"
    kwargs: {structure: adaptive, payout: myerson, price_level: moderate}
arbiter: {policy: {impl: "social_market_env.baselines.arbiters:AlwaysObserve"}}
network: {topology: random, mode: evolving, initial_density: 0.3}
```

Команда:

```bash
python -m social_market_env.run experiments/coalition_stage1.yaml
```

Результат появится в `runs/<дата>_coalition_stage1/`: по каждому шагу цены, планы, соблюдение, SW. Папка `runs/` в Git не попадает.

## 2. Сравнение: `scripts/compare_coalitions.py`

Главный инструмент исследования. Гоняет каждое сочетание «арбитр × агенты × топология × политика» на нескольких seeds и печатает таблицу.

### Что сравнивается

**Политики** (`POLICIES`):

| Имя | Что это |
|---|---|
| `none` | Без коалиций: точка отсчёта |
| `components` | Baseline среды: каждая компонента — картель, деление поровну |
| `stage1` | Наша, этап 1: фиксированный уровень 7 %, Майерсон, без памяти |
| `adaptive` | Наша, полная |
| `no-memory` | Полная без доверия и исключений |
| `fixed-bold` | Фиксированный уровень 15 % |
| `cap-*` | Лестница с фиксированным потолком: контрольные версии бандита |
| `bandit` | С обученным бандитом |
| `equal`, `shapley`, `myerson`, `owen` | Полная, но с другой схемой деления |

**Арбитры** (`ARBITERS`): `observe`, `threshold`, `preventive`, `preventive4` (порог 4 %), `preventive6` (порог 6 %, его не было при обучении бандита).

**Популяции агентов** (`POPULATIONS`): `cartel`, `patient90`, `patient50`, `myopic`, `flaky3`, `askarov` (часть 13).

### Что измеряется

| Колонка | Как считается |
|---|---|
| `profit` | Сумма наград всех агентов / (12 × шаги) |
| `gap%` | Среднее $1-SW/SW^*$ |
| `harm%` | Доля шагов, где среда пометила хоть один план вредным |
| `kept%` | Соблюдавшие / все участники планов |
| `cover%` | Участники планов / (12 × шаги) |
| `edges` | Среднее число рёбер за последние 10 шагов |
| `core%` | Среднее недополучение самой недовольной подгруппы, только для наших политик |
| `rej` | Отклонённые средой планы. Должно быть 0 |
| `ms`, `max` | Среднее и наибольшее время `act` |

Время меряется обёрткой вокруг `act` (функция `timed` в `play`): замер начала и конца каждого вызова.

### Флаги

| Флаг | Смысл |
|---|---|
| `--seeds 5` | Сколько seeds |
| `--first-seed 2000` | С какого seed начинать. 2000+ — отложенные для оценки бандита |
| `--warmup 10` | Сколько эпизодов агенты обучаются перед оценкой |
| `--arbiters`, `--populations`, `--policies`, `--topologies` | Что сравнивать |

Арбитр `preventive` и агент `askarov` в этой ветке не лежат. Их пакеты надо положить в `PYTHONPATH`, см. раздел «Как запустить» в [журнале разработки](../journal.md#как-запустить).

**Пример:**

```bash
python scripts/compare_coalitions.py --seeds 3 --populations cartel patient90 --policies none components adaptive
```

## 3. Обучение бандита: `scripts/train_coalition.py`

1. Создаёт одну политику с `learning='bandit'`.
2. Перемешивает все сочетания: 4 арбитра × 4 популяции × 4 топологии.
3. Каждый эпизод — новая среда со своим сочетанием и seed от 100, но **та же** политика: `env.coalition_policy = policy`.
4. Каждые 20 эпизодов печатает, сколько раз обновлялся каждый вариант.
5. Сохраняет модель в JSON.

Seeds обучения (от 100) и оценки (от 2000) не пересекаются: это главное правило честной оценки обучаемой модели.

```bash
python scripts/train_coalition.py --episodes 128
```

## 4. Тесты

Запуск всех тестов, вместе с тестами среды:

```bash
python -m pytest -q
```

На последнем прогоне — 184 теста, все проходят, около 40 секунд.

### Виды тестов

| Вид | Что проверяет | Пример |
|---|---|---|
| **Математические** | Формулы совпадают с теорией и с эталоном | Шепли из `Шепли.docx` |
| **Сверка с эталоном** | Быстрая версия совпадает с медленной из среды | Майерсон, Оуэн |
| **Модульные** | Один класс в изоляции | Лестница, доверие |
| **Интеграционные** | Политика в настоящей среде | Нет отклонённых планов во всех топологиях |
| **Поведенческие** | Политика ведёт себя как задумано | Постоянный обманщик выпадает из планов |

## Почему тестов так много

Каждая ошибка, найденная в процессе, превратилась в тест, чтобы не вернуться:

| Ошибка | Тест, который её ловит |
|---|---|
| Лестница снижала цену при любом низком соблюдении | `test_ladder_rises_falls_and_remembers_arbiter_ceiling` |
| Исключение за первое нарушение | `test_trust_falls_after_undercut_and_ban_expires` |
| Тестовый агент ошибался в себестоимостях | `test_price_follows_agents_patience` |
| Цена прыгала при смене варианта бандита | `test_arm_cap_limits_price` |

## Что осталось непокрытым

- Страховка не проверена в среде со штрафующим арбитром, только в модульном тесте.
- Тесты в среде идут на 6–8 агентах и коротких эпизодах ради скорости. Основные числа получены скриптом сравнения на 12 агентах и 64 шагах.
- Нет теста на время `act`: его меряет только скрипт сравнения.
