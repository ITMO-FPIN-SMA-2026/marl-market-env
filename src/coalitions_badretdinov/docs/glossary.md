# Коалиция — словарь

> Определения и аббревиатуры проекта. См. также [Коалиция — простое объяснение](overview.md).

## Аббревиатуры

| Сокращение | Расшифровка | Что значит |
|---|---|---|
| **ТЗ** | Техническое задание | Текст лабораторной работы в профиле организации |
| **ЛР** | Лабораторная работа | Вся работа по предмету |
| **SW** | Social Welfare | Общественное благосостояние. В среде это выгода покупателей |
| **SW\*** | Целевое SW | Уровень SW при честной конкуренции, то есть при равновесии Нэша |
| **MARL** | Multi-Agent Reinforcement Learning | Обучение с подкреплением для нескольких агентов |
| **RL** | Reinforcement Learning | Обучение на наградах за действия |
| **CMAB** | Contextual Multi-Armed Bandit | Контекстный бандит: выбор лучшего варианта с учётом ситуации, план этапа 3 |
| **PPO** | Proximal Policy Optimization | Популярный алгоритм RL на нейросетях |
| **MAPPO** | Multi-Agent PPO | PPO для нескольких агентов |
| **QMIX** | — | Алгоритм MARL, объединяющий оценки отдельных агентов в общую |
| **CTDE** | Centralized Training, Decentralized Execution | Обучение с полной информацией, работа только с локальной |
| **GNN** | Graph Neural Network | Нейросеть для данных в виде графа |
| **GRU, LSTM** | Gated Recurrent Unit, Long Short-Term Memory | Нейросети с памятью о прошлых шагах |
| **FP** | False Positive | Ложное срабатывание: арбитр наказал невиновного |
| **FN** | False Negative | Пропуск: вредная коалиция осталась без реакции арбитра |
| **IC** | Incentive Compatibility | Согласованность стимулов: соблюдать план выгоднее, чем обмануть |
| **AIMD** | Additive Increase, Multiplicative Decrease | Схема «медленно вверх, резко вниз». У нас рост тоже умножением |
| **EMA** | Exponential Moving Average | Среднее, где свежие значения весят больше |
| **API** | Application Programming Interface | Договор между частями программы |
| **CR** | Change Request | Запрос на изменение, здесь к команде среды |
| **YAML** | — | Формат файлов с настройками экспериментов |

## Рынок

| Термин | Определение |
|---|---|
| **Агент, продавец** | Участник рынка, который сам назначает цену |
| **Себестоимость** $c_i$ | Затраты агента на единицу товара |
| **Спрос** $Q$ | Сколько всего купят при средней цене: $Q=\max(0,A-BP)$ |
| **Доля рынка** | Какую часть спроса получил агент |
| **Logit-доли** | Модель спроса: покупатели резко уходят к дешёвым. Параметр $\tau$ задаёт резкость. Режим `logit` |
| **`tz_linear`** | Доли по формуле из ТЗ. В этом режиме сговор снижает цену, а не поднимает |
| **Резерв, баланс** | Накопленные деньги агента. При отрицательном резерве агент ограничен, а затем выбывает |
| **`restricted`** | Агент с отрицательным резервом: в планы не допускается |
| **Шаг, эпизод, горизонт** | Шаг — один раунд рынка, эпизод — вся игра, горизонт — число шагов в эпизоде |
| **Seed** | Число, задающее случайность. Одинаковый seed повторяет прогон |

## Теория игр

| Термин | Определение |
|---|---|
| **Равновесие Нэша** | Цены, при которых никому не выгодно менять цену в одиночку. У нас это честная конкуренция |
| **Картель** | Группа, которая назначает цены ради общей прибыли |
| **Наилучший ответ** | Самая выгодная цена при известных ценах остальных |
| **Коалиция** | Группа агентов с общим планом |
| **Гранд-коалиция** | Коалиция из всех агентов |
| **Разбиение** | Деление агентов на непересекающиеся группы |
| **Характеристическая функция** $v(S)$ | Сколько может заработать группа $S$ |
| **$v_\ell(S)$** | Наша версия: сколько заработает $S$, если держит цены плана, а остальные участники плана уходят к Нэшу |
| **$\Delta(C)$** | Дополнительный доход коалиции сверх того, что её участники получили бы поодиночке |
| **$V(C)$** | Наша оценка группы с учётом соблюдения, штрафов и выживания связей |
| **Внешняя опция** $o_i$ | Что агент получит без коалиции. У нас это прибыль по Нэшу |
| **Безбилетник** | Агент вне картеля, который выигрывает от поднятых другими цен |
| **Внутренняя устойчивость** | Никому из участников не выгодно выйти |
| **Внешняя устойчивость** | Никому снаружи не выгодно войти |
| **Вектор Шепли** | Делёжка по среднему вкладу агента во все возможные группы |
| **Вектор Майерсона** | Шепли с учётом сети: ценность есть только у связанных групп |
| **Вектор Оуэна** | Шепли с учётом союзов: сначала делим между союзами, потом внутри |
| **Априорный союз** | Заранее существующая группа для вектора Оуэна. У нас — часть прошлой коалиции |
| **Ядро** | Делёжки, при которых никакой подгруппе не выгодно отделиться |
| **Претензия подгруппы** | Насколько подгруппа стоит больше, чем получает. Положительная претензия значит, что дележ вне ядра |
| **Проекция на ядро** | Сдвиг делёжки, закрывающий претензии подгрупп |
| **Триггер** | Правило наказания: после обмана группа возвращается к конкуренции |
| **Прощающий триггер** | Наказание только за устойчивые нарушения, разовое прощается |
| **Дисконт** $\gamma$, терпеливость $\delta$ | Насколько будущая прибыль важна по сравнению с сегодняшней. 0 — важен только этот шаг |
| **$\delta^*$** | Минимальная терпеливость, при которой обманывать невыгодно |
| **Соблазн** $T_i$ | Прибыль агента, если он один обманет, а остальные держат план |

## Сеть

| Термин | Определение |
|---|---|
| **Граф** $G_t$ | Кто с кем связан на шаге $t$. Арбитр его не видит |
| **Ребро, связь** | Два агента могут договариваться |
| **Связная группа** | Из любого участника можно дойти до любого по связям внутри группы |
| **Компонента связности** | Самая большая связная группа, куда входит агент |
| **Точка сочленения** | Агент, без которого группа распадается на части |
| **Остовное дерево** | Минимальный набор связей, сохраняющий группу связной |
| **Сообщество** | Плотно связанная часть графа |
| **Топология** | Форма сети: `complete` — все со всеми, `star` — звезда, `path` — цепочка, `inner_coalitions` — несколько плотных групп, `random` — случайная |
| **`static`, `evolving`** | Сеть постоянная или меняется на каждом шаге |
| **$H_{ij}$** | Память кооперации пары: от −1 до 1 |
| **$U_{ij}$** | Память о полученной выгоде пары |
| **$C_{ij}$** | Ожидаемая выгода кооперации пары |
| **$c_{ij}$, `link_costs`** | Стоимость связи. Её поднимает арбитр, и связи рвутся чаще |
| **`maintain`, `add`, `remove`** | Просьбы агента сохранить, создать или разорвать связь |

## Коалиция в коде

| Термин | Определение |
|---|---|
| **План** `CoalitionPlan` | Предложение группе: состав, цены, доли |
| **Предложение** `offer` | План глазами одного агента |
| **Котёл** `pool` | Общая прибыль тех, кто соблюдал план. Делится по весам |
| **Вес, доля** | Какая часть котла достаётся агенту |
| **Соблюдение** | Агент вступил и продал по рекомендованной цене с допуском 0.5 |
| **Предатель** `defector` | Вступил, но продал по другой цене |
| **Отказавшийся** `refuser` | Не вступил или не вышел на рынок |
| **Демпинг, `undercutter`** | Наша категория: не соблюдал и продал дешевле плана |
| **Вредная коалиция** | Коалиция, из-за которой SW упало больше порога относительно конкуренции |
| **Лазейка `find_harm`** | Вред считается по каждому плану отдельно, поэтому много мелких планов не помечаются |
| **Лестница цены** `PriceLadder` | Механизм, который поднимает и снижает допустимое падение SW |
| **Потолок** `ceiling` | Запомненный опасный уровень, выше которого лестница не поднимается |
| **Уровень цены** | Допустимое падение SW: `cautious`, `moderate`, `bold`, `cartel` |
| **Доля пути** | Где цена между Нэшем (0) и целевой ценой (1) |
| **Доверие** | Оценка вероятности, что агент соблюдёт план |
| **Страховка** | Временная надбавка к доле оштрафованного участника |
| **Гистерезис** | Новый состав принимается, только если заметно выгоднее старого |
| **Охват** | Какая часть агентов получила план |
| **Оракул** `ValueOracle` | Модуль, который считает равновесия и запоминает их |
| **Битовая маска** | Подмножество агентов, записанное битами числа. Ускоряет перебор групп |
| **Бисекция** | Поиск границы делением отрезка пополам |

## Арбитр

| Термин | Определение |
|---|---|
| **Арбитр** | Участник, который защищает SW и видит только рыночные данные |
| **Санкция** | Штраф одному агенту |
| **`AlwaysObserve`** | Арбитр, который ничего не делает |
| **`ThresholdArbiter`** | Штрафует самого дорогого после скачка средней цены |
| **`PreventiveArbiter`** | Поднимает стоимость подозрительных связей, когда SW долго ниже порога |
| **Индекс арбитра** | Показатель команды арбитра, меньше значит лучше |

## Обучение

| Термин | Определение |
|---|---|
| **Бандит** | Алгоритм, который выбирает из нескольких вариантов и учится по результату |
| **Вариант, рука** | Один из вариантов бандита: у нас это потолок падения SW |
| **Контекст** | Признаки ситуации, по которым бандит делает выбор |
| **Thompson Sampling** | Выбор варианта по случайной выборке из текущей оценки. Неуверенные варианты пробуются чаще |
| **Блок** | Несколько шагов, в течение которых держится один выбор бандита |
| **Отложенные seeds** | Прогоны, которых не было при обучении: на них честно проверяется результат |
| **`cap-*`** | Контрольные версии: один вариант бандита, зафиксированный на весь эпизод |
| **`bandit`** | Политика с обученным бандитом |
| **`preventive6`** | `PreventiveArbiter` с порогом 6 %, которого не было в обучении |

## Режимы и агенты в таблицах

| Название | Что значит |
|---|---|
| `none` | Коалиций нет |
| `components` | Базовая политика среды: каждая компонента — картель |
| `stage1` | Наша политика с постоянным уровнем 7 % и Майерсоном |
| `adaptive` | Полная наша политика |
| `no-memory` | Без доверия и исключений, контроль для вопроса о памяти |
| `fixed-bold` | Постоянный уровень 15 % |
| `cartel` | Все агенты всегда соблюдают: `CartelAgent` |
| `patient90`, `patient50` | Расчётливые агенты с терпеливостью 0.9 и 0.5 |
| `myopic` | Близорукие: важен только текущий шаг |
| `flaky3` | Девять расчётливых и трое случайно предающих |
| `askarov` | Настоящий агент команды `AskarovAgent` |
| `preventive4` | `PreventiveArbiter` с порогом 4 % вместо 8 % |
