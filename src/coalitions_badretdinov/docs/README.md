Код: [`src/coalitions_badretdinov`](..) — сама политика, [`research/`](../research) — вспомогательное: тестовые агенты, сравнение, обучение и эксперименты ТЗ, `tests/test_coalitions_badretdinov_*.py` — тесты. Результаты кратко: [README пакета](../README.md).

## Главное в цифрах

Прибыль агента за шаг. Без коалиций — 43.9. 12 агентов, 64 шага, 10 seeds.

| Результат | Числа | Источник |
|---|---|---|
| Гранд-коалиция на полном графе | +59.8 к прибыли, но падение SW 19 % | [experiments.md](experiments.md) |
| Деление по вкладу против равного | В 2.4–2.8 раза больше прибыли | [journal.md](journal.md) |
| Шепли против Майерсона на разреженной статичной сети | 110 против 44 | [experiments.md](experiments.md) |
| Профилактический арбитр | Срезает прирост коалиции втрое, 26 → 7 | [experiments.md](experiments.md) |
| Арбитр со штрафами за скачки цены | Без эффекта: лестница поднимает цену плавно | [experiments.md](experiments.md) |
| Меняющаяся сеть | Любая стартовая топология приходит к ~35 связям | [experiments.md](experiments.md) |
| Реальный агент команды `AskarovAgent` | Прирост всего +4, соблюдение ~40 % | [experiments.md](experiments.md) |
| Обучаемый бандит | Не обошёл простую лестницу цены | [walkthrough/11](walkthrough/11-learning.md) |

## Заготовка для презентации

ТЗ отводит коалициям 2 слайда: улучшения и результаты.

**Слайд «Улучшения»**

1. Цена «самая высокая из удерживаемых» вместо картельной: ограничение на соблазн предать, $T_i-\text{выплата}_i\le W_i(\text{выплата}_i-\pi_i^N)$ — [walkthrough/07](walkthrough/07-pricing.md).
2. Лестница цены, которая сама находит порог арбитра, не зная его, — [walkthrough/07](walkthrough/07-pricing.md).
3. Деление на игре запланированных цен, быстрые Шепли и Майерсон на битовых масках: миллисекунды вместо 2 с — [walkthrough/08](walkthrough/08-payouts.md).
4. Память о доверии с прощающим триггером — [walkthrough/10](walkthrough/10-beliefs.md).

**Слайд «Результаты»** — таблица «Главное в цифрах» выше, графики из [experiments.md](experiments.md).

**Цепочки «изменение метода → поведение → награды»** для защиты — история ошибок этапа 2 в [journal.md](journal.md):

| Изменение | Поведение | Награда |
|---|---|---|
| Лестница снижает цену при любом низком соблюдении | Цена падает до Нэша даже когда план выгоден | Хуже фиксированной цены почти везде |
| Снижать только при убытке соблюдавших | Цена держится при частичном соблюдении | 51.4 → 71.1 на случайных обманщиках без арбитра |
| Исключение за первое нарушение → прощающий триггер | Охват растёт: 66 → 96 % на `patient50`, 40 → 84 % на `AskarovAgent` | Не хуже ни на одном типе агентов, на этих двух +1.6–1.8 |
| Майерсон → Шепли на разреженной сети | Периферия перестаёт срывать сговор | 44 → 110 |

## Как воспроизвести

После установки среды по [README](../../../README.md), из корня репозитория:

```bash
python -m pytest -q
```

```bash
python -m coalitions_badretdinov.research.tz_experiments topology --seeds 10
```

Остальные эксперименты — `structure`, `evolution`, `arbitrage`. Для арбитров и агентов других команд нужны их пакеты в `PYTHONPATH`, см. [journal.md](journal.md#как-запустить).
