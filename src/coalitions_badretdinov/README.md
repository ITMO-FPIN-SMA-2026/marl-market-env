# coalitions_badretdinov — политика коалиций

**Автор:** Бадретдинов Антон

Политика коалиций для `social_market_env` (контракт `2.0.0`), класс `coalitions_badretdinov:AdaptiveCoalitionPolicy`.

## Идея

Коалиция — посредник, который видит граф связей и каждый шаг предлагает агентам планы: кто объединяется, по какой цене продаёт и как делится общая прибыль. Заставить агентов он не может, поэтому главный принцип — **не самая высокая цена, а самая высокая удерживаемая**.

| Механизм | Что делает |
|---|---|
| Кандидаты и разбиение | Связные группы: компоненты, сообщества по памяти кооперации, прошлые группы. Выбор непересекающихся групп по оценке $V(C)$, удержание состава |
| Лестница цены | Сама находит порог арбитра по его реакции: растёт после хороших шагов, снижается после реакции арбитра или убытка группы |
| Ограничение на соблазн | Цена не выше той, при которой каждому участнику выгоднее соблюдать план, чем обмануть: $T_i-\text{выплата}_i\le W_i(\text{выплата}_i-\pi_i^N)$ |
| Деление прибыли | Поровну, Шепли, Майерсон, Оуэн и свой гибрид: Майерсон + проекция на ядро + страховка от штрафов. Счёт на битовых масках за миллисекунды |
| Память | Доверие к агентам с прощающим триггером, ожидаемые штрафы, выживание связей |
| Обучение | Контекстный бандит над потолком цены. Выигрыша не дал, по умолчанию выключен |

## Подключение

```yaml
coalitions:
  policy:
    impl: "coalitions_badretdinov:AdaptiveCoalitionPolicy"
    kwargs: {horizon: 100, network_mode: evolving}
```

`horizon` и `network_mode` должны совпадать с `horizon` и `network.mode` конфига: в наблюдении коалиции их нет. Остальные параметры имеют значения по умолчанию, полный список — в [`settings.py`](settings.py).

Готовый конфиг: [`coalitions_badretdinov.yaml`](coalitions_badretdinov.yaml), 12 `CartelAgent`, без арбитра.

```bash
python -m social_market_env.run src/coalitions_badretdinov/coalitions_badretdinov.yaml
```

## Результаты

12 агентов, 64 шага, 10 seeds, 95 % бутстреп-интервалы. Основные агенты — расчётливые (`PatientAgent`, терпеливость 0.9), проверка на реальном агенте команды — `AskarovAgent`. Прибыль агента за шаг без коалиций — 43.9.

| Эксперимент ТЗ | Результат |
|---|---|
| Топология (статичная сеть) | Полный граф +59.8 [37.9; 77.7], звезда +10.1, три группы +4.0, цепочка 0 |
| Структура коалиций | Гранд-коалиция +59.6 против +12.9 у частных, устойчивее (соблюдение 86 % против 60 %), но снижает SW на 19 % |
| Эволюция сети | Меняющаяся сеть забывает стартовую форму: любая топология приходит к ~35 связям. Коалиция сама уплотняет сеть |
| Арбитраж | Профилактический арбитр срезает прирост втрое, +26 → +7. Штрафы за скачки цены не работают: лестница поднимает цену плавно |
| Реальный агент | С `AskarovAgent` прирост +4.0: он соблюдает около 40 % планов, арбитры ни разу не вмешались |

**Главные выводы:**

- **Справедливое деление поднимает удерживаемую прибыль** в 2.4–2.8 раза по сравнению с равным: при равной доле дешёвым продавцам выгоднее обмануть.
- **На разреженной статичной сети Шепли в 2.5 раза лучше Майерсона** (110 против 44): Майерсон обделяет периферию, и она срывает сговор.
- **Лестница находит порог арбитра без его знания**: при пороге 8 % — 67.8 против 68.3 у подогнанной цены, при пороге 4 % сохраняет сеть (23.7 связей против 9.0).
- **Память работает как разрешение поднять цену**: без арбитра почти удваивает прибыль (134 против 71), против профилактического арбитра не помогает.

**Не сделано:** адаптация (нужны новые версии других команд), сравнение с MARL-арбитром (нужен PyTorch), проверка на долях из ТЗ (`tz_linear`).
