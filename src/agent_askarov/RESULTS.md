# Результаты проверки рыночного агента

Основная готовая к использованию версия — `AskarovAgent` без загруженной
Q-таблицы, конфигурация `src/agent_askarov/experiments/agent_askarov.yaml`. Она использует
экономическую оценку, реакцию на предыдущий штраф и правила управления связями.
На проверенном наборе её средняя индивидуальная награда немного выше
`BestResponseAgent`. Обученная в этом эксперименте Q-таблица результат ухудшила;
поэтому она не включена в основной конфиг.

## Условия

- Дата проверки: 29 октября 2026 года.
- Python 3.13.5, NumPy 2.5.4, NetworkX 3.7, PyYAML 6.0.3.
- 12 продавцов; сравнивается индивидуальный результат продавца № 0.
- Себестоимости от 15 до 22; модель долей спроса `logit`; параметры из
  `src/agent_askarov/experiments/agent_askarov.yaml`.
- Обучение: 72 эпизода по 60 шагов, seeds `0, 1, 2`, 4 320 обновлений Q,
  13 посещённых категорий состояния, эволюционирующая сеть.
- Оценка: seeds `100, 101, 102`, которые не использовались для обучения.
- Четыре топологии: `complete`, `star`, `path`, `inner_coalitions`.
- Два режима сети: `static`, `evolving`.
- Три режима окружения: `competition`, `cooperation`, `mixed`.
- Итого 72 условия для каждой политики, четыре политики, 288 оценочных эпизодов
  по 60 шагов. В каждом условии у всех политик одинаковые начальные
  себестоимости и reset seed. В оценке ни один компонент не обучается.

Режим `competition` — независимые соперники `BestResponseAgent` без коалиций
и вмешательства. `cooperation` — соперники `CartelAgent`, коалиции по связным
компонентам, арбитр наблюдает. `mixed` — состав из YAML: коалиционные продавцы,
один независимый продавец, один случайный, пороговый арбитр со штрафом 50.

## Общий результат

Средняя награда — сумма чистых наград продавца № 0 за 60 шагов, затем усреднённая
по 72 условиям. Штрафы, перераспределение коалиционного дохода и плата за новые
связи уже учтены. Денежные величины условные.

| Политика продавца № 0 | Средняя награда | Средняя дисконтированная награда при γ = 0.9 | Среднее благосостояние покупателей | Выживание |
| --- | ---: | ---: | ---: | ---: |
| `BestResponseAgent` | 27 928.86 | 3 850.40 | 2 970.82 | 100% |
| `CartelAgent` | 5 149.77 | 845.33 | 2 854.69 | 100% |
| `AskarovAgent` без обучения | 28 105.81 | 3 992.61 | 2 970.05 | 100% |
| `AskarovAgent` с обученной Q-таблицей | 22 240.41 | 3 186.76 | 2 985.79 | 100% |

Экономическая версия без обучения дала примерно **+0.63%** к средней суммарной
награде `BestResponseAgent` на этом наборе. Это небольшой наблюдаемый эффект,
а не доказательство статистически значимого или универсального преимущества.
Обученная версия получила примерно **−20.87%** относительно экономической
версии без обучения. По дисконтированной цели обучение также уступило ей.

Все продавцы № 0 выжили. Это не означает, что проверена устойчивость к любому
арбитру или любому штрафу: здесь использованы только описанные политики.

## Разделение по режимам соперников

В каждой ячейке — средняя собственная суммарная награда по 24 условиям:
4 топологии × 2 режима сети × 3 seed.

| Режим | `BestResponseAgent` | `CartelAgent` | Наш без обучения | Наш после Q-learning |
| --- | ---: | ---: | ---: | ---: |
| Конкуренция без коалиций | 2 806.81 | 2 806.81 | 2 807.13 | 2 758.50 |
| Кооперативные соперники | 68 404.42 | 11 653.89 | 68 941.08 | 53 449.49 |
| Смешанные соперники и пороговый арбитр | 12 575.34 | 988.60 | 12 569.22 | 10 513.23 |

Результат существенно зависит от соперников. Большая индивидуальная прибыль
в кооперативном режиме возникает, в частности, за счёт выгодной независимой
цены против продавцов, следующих коалиционной рекомендации. Это индивидуальная
выгода; она не доказывает устойчивость общего коалиционного поведения.

На этой оценке оба варианта нашего агента не принимали коалиционные предложения.
Это допустимый выбор индивидуального продавца, а не доказательство того, что
коалиции всегда невыгодны. В других предложениях, например с большой долей
выплаты и разумной ценой, агент может вступить в коалицию — это отдельно
проверяется тестами. Для исследования устойчивых коалиций нужны совместные
эксперименты с коалиционной командой.

## Вывод об улучшении

Реализованный индивидуальный вклад — оценка собственной выгоды предложения
вместо безусловного вступления в коалицию, несколько осмысленных вариантов цены,
учёт финансовых ограничений и прошлых санкций, управление доступными связями.
Сравнение поддерживает пользу такого выбора относительно безусловного
`CartelAgent` в проверенных условиях. Оно не изолирует вклад каждого правила:
для этого нужны отдельные абляции.

Гипотеза «после 72 эпизодов табличное обучение улучшает эту экономическую
политику» **не подтвердилась**. Возможные причины — слишком грубое укрупнение
ситуаций, разные доходности внутри одной категории и недостаточный опыт для
всех вариантов. Это гипотезы для следующей итерации, а не установленная причина
регрессии. Независимая оценка потребует новых seeds, если по этим результатам
далее подбирать состояния и параметры.

- Оценочная команда проверила, что Q-таблица и счётчик обновлений не изменились.
- Исходники `src/social_market_env`, исходный README, `pyproject.toml` и
  `experiments/demo.yaml` остались без изменений.

## Как воспроизвести

Из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m agent_askarov.experiment train --episodes 72 --horizon 60
.\.venv\Scripts\python.exe -m agent_askarov.experiment benchmark --horizon 60
```

Исходные результаты находятся в `runs/askarov_agent/policy.training.json`,
`runs/askarov_agent/comparison.json` и `runs/askarov_agent/comparison.md`.
Содержимое `runs/` исключено из Git правилами исходного проекта; этот отчёт
сохраняет выводы и рецепт воспроизведения вместе с кодом.

Эта проверка относится к индивидуальному агенту. Распределения Шепли,
Майерсона и Оуэна, обучаемый арбитр и три последовательных цикла взаимной
адаптации остаются частью совместной лабораторной других ролей.
