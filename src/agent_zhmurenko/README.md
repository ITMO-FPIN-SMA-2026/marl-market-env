# Рыночный агент Жмуренко

**Автор — Владимир Жмуренко**

## Назначение и возможности

`ZhmurenkoVladimirAgent` выбирает цену в повторяющейся рыночной игре с динамической сетью. Он учитывает себестоимость, наблюдаемые цены конкурентов, финансовый резерв и условия текущего коалиционного предложения. Агент может выставить собственную цену, принять предложение по рекомендованной цене или пропустить торговый шаг.

## Архитектура

Состояние рынка описывается тремя дискретными признаками.

- **Конкурентные цены.** Разность между медианой последних публичных цен соперников и собственной себестоимостью делится на `tau`. Семь категорий включают отсутствие наблюдений.
- **Коалиционное предложение.** Учитываются наценка рекомендованной цены и относительная доля выплаты `weight × members`. Для отсутствующего или недопустимого предложения предусмотрена отдельная категория.
- **Финансовый резерв.** Выделяются обычное, низкое и ограниченное состояния.

Такое представление даёт до 168 базовых состояний. Из 12 действий восемь задают наценку к себестоимости, два ставят цену на `0.2 tau` выше или ниже медианы цен конкурентов, оставшиеся два позволяют принять предложение или пропустить торговлю. Агент исключает недоступные действия при выборе и при вычислении следующего максимума Q.

Агент обучается методом табличного Q-Learning по фактической награде среды. Структурное улучшение — двухуровневая оценка действий:

- **Shared Q** накапливает опыт по базовым состояниям.
- **Regime Q** уточняет оценки для снижения, стабильности и роста конкурентных цен. Режим определяется по изменению медианы цен конкурентов между последовательными наблюдениями, с порогом `0.1 tau`.

Агент использует общую оценку, пока каждое доступное действие в режимной строке не было опробовано хотя бы восемь раз. После этого он смешивает общую и специализированную оценки с весом `n / (n + 64)`, где `n` — минимальное число посещений среди доступных действий. Вес специализации растёт с накоплением опыта. Вариант `flat` использует Shared Q, а вариант `regime` добавляет режимные оценки.

## Обучение и подключение модели

### Штатный запуск

Поставляемая модель `regime_1` получена за 2 500 обучающих эпизодов и 125 000 обновлений. Класс `agent_zhmurenko:ZhmurenkoVladimirAgent` автоматически загружает `models/q_agent.json` из своего пакета. При загрузке проверяются совместимость таблицы и параметры рынка. Во время оценки значения Q остаются замороженными.

Из корня репозитория в активном окружении Python:

```powershell
python -m pip install -e .
python -m social_market_env.run experiments/agent_zhmurenko.yaml --runs-dir runs/agent_zhmurenko --strict
```

В YAML можно указать другую совместимую таблицу через `kwargs: {model_path: 'путь/к/таблице.json'}`. Режим с пустой таблицей включается явно через `kwargs: {fresh: true}`.

### Воспроизведение обучения

Скрипты обучения и анализа находятся в `research/`. Каждый повтор обучает `flat` и `regime` при одинаковой ротации позиций и составов, с отдельными seed между повторами. Параметры обновления — `alpha=0.12`, `gamma=0.9`, масштаб награды 100 и спад `epsilon` от 0,35 до 0,08. В обучении 9 из 10 эпизодов используют `w_coop=0` для сокращения времени расчёта. Каждый десятый эпизод и итоговая оценка используют `w_coop=1`.

Для нового исследования укажи отдельный каталог результатов:

```powershell
$root = Join-Path ([IO.Path]::GetTempPath()) 'ITMO_Q_NEW_RUN'
python -m agent_zhmurenko.research.experiment train --root $root --repeat 0
python -m agent_zhmurenko.research.experiment train --root $root --repeat 1
python -m agent_zhmurenko.research.experiment train --root $root --repeat 2
```

Флаг `--resume` продолжает обучение с последнего общего чекпойнта пары. Параметр `--max-episodes` должен задавать бюджет выше уже завершённого числа эпизодов.

После завершения всех трёх повторов команда `bundle` выбирает модель по валидации, до итоговой оценки. Она обновляет `models/q_agent.json` и `models/provenance.json` в пакете.

```powershell
python -m agent_zhmurenko.research.analysis bundle --root $root
```

## Результаты апробации

В индивидуальной оценке на 12 новых seed по семи сценариям поставляемая модель получила среднюю награду **15 086,30**, а простая стратегия с наценкой в тех же условиях — **10 292,44**. Каждую из этих политик оценивали в 84 эпизодах.

В совместной игре с 12 продавцами агент прошёл проверку в строгом режиме. При включении коалиций его средняя награда выросла с **808,45 до 901,26** и увеличилась в 37 из 48 парных сравнений. В полной конфигурации агент принял **136 из 1 082** предложений и во всех 136 случаях соблюдал рекомендованную цену. По средней награде он уступил остальным типам продавцов в этом составе.

## Ограничения исследования

Режимная специализация апробирована сравнением `regime` и `flat` при одинаковом протоколе обучения. Оценки эффекта различались между повторами. Устойчивое преимущество специализации по средней награде в проведённой серии не установлено.

Индивидуальная и совместная серии различались по составу продавцов, длительности эпизодов и условиям игры, поэтому абсолютные награды напрямую несопоставимы. Результат совместной игры относится к проверенному составу из 12 продавцов, себестоимостям от 15 до 22, четырём топологиям, статической и динамической сети и использованным правилам формирования коалиций.
