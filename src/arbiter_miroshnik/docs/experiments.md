# Командные эксперименты PPO + GRU

Используются настоящий `social_market_env`, штатная награда, обычная адаптивная
политика коалиций и эволюционирующая сеть. Источники четырёх командных продавцов
закреплены commit и SHA-256 в manifest каждого каталога серии.

| Локальная серия | Игр на модель | PPO-update | Средняя разница SW | 95% интервал |
| --- | ---: | ---: | ---: | --- |
| `runs/transferred_ppo` | 128 | 16 | +19.694 | [-148.113; 131.427] |
| `runs/transferred_ppo_latest` | 64 | 8 | +60.325 | [-95.211; 294.390] |
| `runs/transferred_ppo_amd` | 72 | 9 | +68.343 | [-84.269; 223.544] |

Каждая оценка использует три модели и 20 миров на модель. Для AMD-серии
выделен новый блок seed, начинающийся с 1,500,000,000. Последние восемь игр
каждой модели и PPO-update AMD-серии выполнены на RX 6600 XT через ROCm.

Во всех трёх финальных проверках greedy-политики не штрафовали; точность
санкций не определена. Интервалы изменения SW включают ноль. С теми же
продавцами отключение не вмешивающегося арбитра не меняет результат.
Разница между адаптированными популяциями не доказывает пользу активного
вмешательства, а отсутствие санкций не доказывает умение выявлять сговор.

Полная квалификация требует положительного эффекта SW, точности санкций не
ниже 90%, достаточного числа фактических санкций и независимых обучающих
повторов. Этот результат пока не получен. Метрики других архитектур или
собственного logit-рынка не являются результатами этого PPO + GRU.

Полные локальные отчёты: `target_evaluation_002.json` в первых двух сериях и
`target_evaluation_003.json` в AMD-серии. Краткая версия для Git —
[`../research/results.json`](../research/results.json). Полные обучающие состояния
и тяжёлые логи исключены из Git; исходные архивы сохраняются отдельно.
Начальный checkpoint для примера включён в [`../checkpoints/`](../checkpoints/README.md).
