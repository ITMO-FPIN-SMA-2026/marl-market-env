# Начальный checkpoint PPO + GRU

`initial_model_0.pt` включён в Git и Python-пакет для запуска
`arbiter_miroshnik.yaml`.

- Источник: `runs/transferred_ppo/initial_model_0.pt`, побайтовая копия.
- Размер: 118024 байта.
- SHA-256: `42470a3e2785eb9198eef7bc96d230a16589cd6bd80c8d133be36c0f8204973c`.
- Формат: checkpoint схемы 4, загружаемый через `torch.load(weights_only=True)`.
- Actor и critic предварительно обучены на исходном рынке: 64 эпизода,
  8 обновлений PPO; при переносе оптимизаторы и траектории сброшены,
  добавлена калибровка штатной среды.
- В штатной среде этот начальный снимок ещё не дообучен:
  `episodes_seen=0`, `updates=0`. Последующие исследовательские состояния
  остаются отдельно в `runs/`.

Калибровка, настройки и обе сети находятся внутри checkpoint.
Исторический абсолютный путь в metadata служит сведением о происхождении;
для загрузки он не используется. Этот файл обеспечивает воспроизводимый запуск,
но не подтверждает пользу арбитра или точность санкций.
