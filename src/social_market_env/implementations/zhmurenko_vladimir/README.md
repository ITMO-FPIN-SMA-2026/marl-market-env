# Рыночный агент Жмуренко: компактный Q-Learning

Публичный класс: `social_market_env.implementations.zhmurenko_vladimir:ZhmurenkoVladimirAgent`.
Основная конфигурация — **`experiments/zhmurenko_agent.yaml` в корне репозитория**.
Среда, контракты и зависимости проекта не изменяются.

## Обычный запуск для команды

В комплект входит настоящая обученная таблица `models/q_agent.json`. Класс автоматически
находит её относительно собственного файла, независимо от рабочего каталога. Отсутствующий,
пустой или несовместимый checkpoint вызывает ошибку. Пустой режим включается только явно:
`kwargs: {fresh: true}`. Это контроль до обучения, а не поставляемая обученная модель.

```powershell
$env:PYTHONPATH = (Resolve-Path 'src').Path
$env:PYTHONDONTWRITEBYTECODE = '1'
python -m social_market_env.run experiments/zhmurenko_agent.yaml `
  --runs-dir "$env:USERPROFILE/Downloads/ITMO_Zhmurenko_Q/runs" --strict
```

Можно передать собственный checkpoint через `kwargs: {model_path: 'путь/к/таблице.json'}`.
JSON содержит схему действий/состояний, рыночные параметры, настройки, значения Q,
счётчики посещений, число обновлений и происхождение модели. Число обновлений сверяется
с суммой посещений. Состояния/действия и рынок должны совпадать с сохранённой схемой.

## Устройство реализации

Политика использует относительные ценовые действия, компактные категории,
нулевую начальную Q-таблицу и обученную общую оценку для редких исторических контекстов.
Экономический расчёт прибыли или best-response oracle в выборе действия отсутствует.
За резервную стратегию не выдаётся результат обучения: до обучения и после него
выполняются отдельные проверки. Начальный режим совпадает с простой наценкой `cost + tau`.

## Состояния и действия

Общая строка состоит из трёх категорий:

- Конкурентное давление: медиана публичных прошлых цен соперников минус собственная
  себестоимость, делённая на `tau`. Границы: −0.5, 0.5, 1.5, 3, 6; отдельный код отсутствия данных.
- Предложение: нет/недопустимо либо три диапазона наценки рекомендации (границы 1.5 и 4 `tau`)
  и два диапазона относительной доли выплат `weight × members` (граница 1).
- Резерв: нормальный, меньше четверти опорного резерва, отрицательный/ограниченный.

Себестоимость учитывается в относительных признаках и в каждой цене. Грубые диапазоны
объединяют близкие рынки и позволяют накапливать опыт вместо огромной разреженной таблицы.
Общих состояний не больше `7 × 8 × 3 = 168`.

12 действий: наценки `tau × (0.5, 0.8, 1, 1.1, 1.2, 1.6, 2.5, 4)`, цена ниже/выше
медианы соперников на `0.2 tau`, точное принятие текущего предложения, пропуск торговли.
Недопустимые действия исключаются и при выборе, и при вычислении следующего максимума Q.
Цены ниже себестоимости не предлагаются; это ограничивает возможное коалиционное субсидирование.
Запросы изменения связей агент не отправляет. Сеть меняется по штатным правилам среды.

## Исследуемое структурное улучшение

Механизм — специализация Q по направлению изменения конкуренции с защитой от нехватки опыта.
Одно текущее ценовое окружение может возникнуть при росте или падении рынка. По двум
последовательным публичным наблюдениям выделяются падение/стабильность/рост, с зоной
нечувствительности `0.1 tau`. Дополнительных строк не больше `3 × 168 = 504`.
Всего максимум 672 строки по 12 значений Q и счётчиков. Нейросетей нет.

Общая таблица обучается на всех переходах. Режимная строка начинается с уже обученной
общей оценки. Пока каждое допустимое действие в строке не испытано хотя бы 8 раз,
решение полностью опирается на общую обученную таблицу. Затем используется один общий
вес строки `min_visits / (min_visits + 64)`. Общий вес сохраняет ранжирование при
одинаковой добавке ко всем Q; независимые веса отдельных действий этого не гарантируют.

Контроль `flat` отключает специализацию; `regime` включает её. Простое применение
Q-learning не заявляется исследовательской новизной. Польза механизма устанавливается
только сравнением этих вариантов при одинаковом обучении и начальных условиях.

Q обновляется по настоящей награде среды: `Q ← Q + alpha × (reward/100 + gamma × max Qnext − Q)`.
Параметры: `alpha=0.12`, `gamma=0.9`, epsilon от 0.35 до 0.08. Терминальный переход
не использует bootstrap. История очищается на reset; preview следующего наблюдения её не меняет.
В eval таблицы не обновляются. Известное состояние, изученное выбранное действие,
применение специализации и фактическое отличие от начальной стратегии считаются отдельно.

## Обучение и сокращённая проверка

```powershell
$module = 'social_market_env.implementations.zhmurenko_vladimir'
$root = "$env:USERPROFILE/Downloads/ITMO_Q_NEW_RUN"
python -m "$module.experiment" train --root $root --repeat 0
# Повторы 1 и 2 выполняются с --repeat 1 и --repeat 2.
python -m "$module.analysis" bundle --root $root
```

Для повторов используется одинаковая ротация ID и составов для `flat`/`regime`, разные
обучающие seed, коалиционные предложения и меняющиеся цены. Проверка остановки начинается
после 1000 эпизодов, каждые 250; предел 2500 не означает автоматически достигнутой сходимости.
Срезы сохраняются. `--resume --max-episodes N` продолжает последний общий блок пары;
незавершённые записи сохраняются отдельно, не удаляются. Точное продолжение проверено тестом.

Для скорости 9 из 10 обучающих эпизодов используют штатный параметр сети `w_coop=0`,
каждый десятый — исходный `w_coop=1`. История/полезность и эволюция связей остаются включены.
Это явно записывается в конфигурациях. Итоговая оценка всегда использует исходное значение 1.
Код среды не подменяется и не изменяется.

Сокращённый итог: 12 новых seed, 7 составов, 8 политик — 672 эпизода.
Обученные Q-агенты сравниваются с пустой таблицей и экономической стратегией в одинаковой
позиции, с одинаковыми cost и seed.

Модель для команды выбирается только по валидации, до итоговых seed. Приоритет выбора —
наименьшее относительное проседание по сценариям, затем средняя относительная награда.

Полноценное совместное переобучение всех участников не заявляется.
