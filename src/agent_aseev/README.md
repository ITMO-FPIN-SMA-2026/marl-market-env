# agent_aseev — рыночный агент «Q-learning + наценки»

**Автор:** Асеев Георгий Важевич

Рыночный агент для `social_market_env` (контракт `2.0.0`), класс `agent_aseev:GeorgiiAgent`.

## Идея

Табличный Q-learning. Агент выбирает не абсолютную цену, а **наценку к своей себестоимости**,
поэтому одна выученная таблица подходит продавцу с любым `cost`.

**Действия (9):**
- 8 наценок: цена = `cost × {1.05, 1.15, 1.25, 1.35, 1.5, 1.7, 2.0, 2.5}`;
- «принять оффер»: вступить в предложенную коалицию и поставить рекомендованную цену
  (доступно, только если оффер есть и агент не в ограничении).

**Состояние (4 признака, 24 состояния):**
1. своя прошлая цена относительно средней по рынку: дешевле (<0.97) / рядом / дороже (>1.03);
2. прибыль на прошлом шаге: да / нет;
3. ограничение из-за отрицательного резерва: да / нет;
4. есть ли оффер коалиции: да / нет.

Награда — то, что агент получил за шаг (прибыль + выплата коалиции − штрафы − плата за связи), делённая на 100.
Параметры: `alpha = 0.1`, `gamma = 0.95`, ε убывает с 1.0 до 0.05 (×0.99 за эпизод).

## Подключение

```yaml
agents:
  overrides:
    0: {impl: "agent_aseev:GeorgiiAgent"}
```

По умолчанию загружаются обученные веса `georgii_q.json` из этой папки.
`kwargs: {checkpoint: null}` — агент без обучения (пустая таблица, всегда ставит `cost × 1.05`).

Готовый конфиг: `src/agent_aseev/agent_aseev.yaml` (одиночка на месте 0 среди 11 `CartelAgent`).

```bash
python -m social_market_env.run src/agent_aseev/agent_aseev.yaml
```

## Обучение

```bash
python -m agent_aseev.train <config.yaml> 200
```

200 эпизодов по 100 шагов на сидах 1000–1199, веса сохраняются в `georgii_q.json`.
Текущие веса обучены в постановке «одиночка на месте 0 среди 11 `CartelAgent`,
политика коалиций команды (`coalition_policy:AdaptiveCoalitionPolicy`), без арбитра».

## Результаты (20 сидов, горизонт 100)

| Постановка | Агент | Best response |
|---|---|---|
| Одиночка среди 11 картельщиков, без арбитра | 9 166 ± 566 | 8 926 |
| То же, с удорожанием связей (`PreventiveArbiter`) | 5 247 | 6 230 |

Популяция из 12 копий (арбитр наблюдает): разрыв SW −2.3 %, средняя цена 23.0,
прибыль всех 29.7 тыс., Gini 0.19 (у BR: 0 %, 24.1, 52.6 тыс., 0.21).

**Выученное поведение:** низкая наценка (×1.05–1.5); при оффере в удачный момент агент не вступает
в картель, а подрезает его ценой ×1.05 («безбилетник»); в коалицию вступает после убыточного шага.
В популяции копии подрезают друг друга — ценовая война, цена ниже равновесия Нэша.
