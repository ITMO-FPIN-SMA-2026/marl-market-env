# Данные и воспроизводимость общего эксперимента

## Постановка

- 15 продавцов: по три экземпляра политик Асеева, Аскарова, Твердохлеба, Жмуренко и Родиной.
- Горизонт среды и коалиционной политики: 100 шагов; seed `2000000`–`2000019` для каждого варианта.
- `mode: eval`, `strict: true`; ошибки и fallback в записях шагов отсутствуют.
- Полный вариант: `experiments/config.yaml`; арбитр загружен из **начального** `src/arbiter_miroshnik/checkpoints/initial_model_0.pt`, режим greedy.
- Контроль 1: те же продавцы и коалиции, арбитр `AlwaysObserve`.
- Контроль 2: те же продавцы, без коалиций, арбитр `AlwaysObserve`.
- Один и тот же файл `tverdokhleb_policy.json` использован в трёх вариантах. Обучение воспроизведено отдельно: 300 эпизодов, горизонт 100, 29 941 обновление Q-таблицы. Отчёт обучения и оценочный конфиг сохранены рядом с моделью.

Команда обучения из корня репозитория:

```bash
.venv/bin/python -m agent_tverdokhleb.experiment train \
  --config src/agent_tverdokhleb/agent_tverdokhleb.yaml \
  --episodes 300 --horizon 100 --min-updates 10000 \
  --eval-seeds 2000100 2000101 2000102 \
  --output report/defense/data/tverdokhleb_policy.json
```

## Первичные данные

Каталог `data/runs/` содержит 60 папок эпизодов с `summary.json`, `episode.json` и `steps.jsonl`. Конфигурации контролей находятся в `data/controls/`; сводка `data/study_summary.json` вычислена скриптом `build/analyze_study.py`. Скрипт проверяет ровно 100 шагов в каждом эпизоде и отсутствие событий компонентов.

Из корня репозитория:

```bash
.venv/bin/python report/defense/build/generate_controls.py
.venv/bin/python -m social_market_env.run experiments/config.yaml --runs-dir report/defense/data/runs
.venv/bin/python -m social_market_env.run report/defense/data/controls/coalitions_no_arbiter.yaml --runs-dir report/defense/data/runs
.venv/bin/python -m social_market_env.run report/defense/data/controls/no_coalitions_no_arbiter.yaml --runs-dir report/defense/data/runs
.venv/bin/python report/defense/build/analyze_study.py
```

Интервалы — 95% перцентильные бутстреп-интервалы среднего по 20 seed (10 000 повторных выборок, генератор seed 2026). Для сравнения вариантов бутстреп применяется к двадцати **парным разницам**. Интервалы описывают неопределённость этой выборки seed; они не охватывают смену популяции, гиперпараметров или повторное обучение моделей.
