# История экспериментов с MLP

Это документация отдельного эксперимента. Основной арбитр восстановлен как
PPO + GRU: [актуальная инструкция](ARBITER.md). Описанное ниже исключение PPO
из рабочего кода относится к прежнему состоянию проекта и отменено.

Рабочая политика — небольшой MLP с 1921 параметром и историей публичных цен.
Входы: текущие цены, общедоступная SW и её изменение, лаги 1–3,
сводки за пять раундов и характеристики совпадения цен. ID продавца не является
входным признаком. Граф, составы коалиций, издержки и резервы на вход не подаются.
Для выбора действий достаточно NumPy; PyTorch нужен только для обучения.
Нейросеть обучается классифицировать вредное участие; размер штрафа и порог
подбираются по результатам адаптации продавцов и чистой SW. Это обучение
предиктора с подбором управления, а не сквозной RL арбитра по награде SW.
Фактические результаты и готовые checkpoint: [RESULTS.md](RESULTS.md).

```bash
python3 -m pip install -r requirements-arbiter.txt
python3 -m market_rl.learn_arbiter --out runs/my_arbiter
```

Для согласованного logit-режима:

```bash
python3 -m market_rl.train --demand-model logit --episodes 1000 --output runs/logit_market
python3 -m market_rl.learn_arbiter --market runs/logit_market/agents.json \
  --out runs/new_logit_arbiter --replicas 8 --test-worlds 50 --domain 20000000
```

Арбитр заново обучается на этом рынке. Его checkpoint содержит тип спроса,
параметры, нормировку SW и определение вреда. Несовместимые веса отвергаются.
После повторного обучения параметры управления проверяются на новых популяциях
до открытия итоговых сценариев. Результаты этой проверки лежат в `validated/`.

Пайплайн собирает независимые обучающие и проверочные истории, сравнивает
модель текущего раунда и модель с лагами на трёх инициализациях, адаптирует
рыночных агентов, затем обновляет арбитра на изменившемся распределении.
Для отдельного подбора управления по уже сохранённым весам:

```bash
python3 -m market_rl.learn_arbiter \
  --predictor runs/arbiter_learning_v1/round1.json \
  --out runs/my_validation --domain 3000000
```

Каждый запуск использует новый каталог. `--domain` разделяет seed новых
разработочных и итоговых сценариев. Итоговые эпизоды не используются для
обучения или выбора порога и размера штрафа.

## Чему учится модель

Обучаемый предиктор оценивает вероятность вредного коалиционного участия.
Метки формирует только оценщик среды: совместная цена повышает среднюю цену
закупки и уменьшает SW более чем на 5% относительно контрфактического рынка
при неизменных ценах внешних продавцов. В исходном режиме участники используют
свои индивидуальные предложения. В logit-режиме используются их точные
конкурентные цены из равновесия Нэша на заданной сетке. Равновесие вычисляется
перебором оценщиком и не передаётся арбитру. Денежное распределение текущего
коалиционного прироста использует индивидуальные предложения в обоих режимах.
В обучении присутствуют дорогие независимые продавцы как отрицательные примеры.

На исполнении арбитр получает только `PublicObservation`. Решение зависит
от обученной вероятности и порога, выбранного на разработочных сценариях.
Порог управляет компромиссом между ошибочными штрафами и пропусками.
Сохраняются финансовые ограничения и пауза между штрафами. Доступны наблюдение
и штраф одному продавцу; изменение стоимости связей остаётся действием среды
для других политик.

Награда оценщика:

`-alpha*abs(SW-SW_target)/SW_target - beta*intervention - lambda_fp*FP - lambda_fn*FN`.

В исходном режиме `SW_target=A²/(2B)`. В logit-режиме
`SW_target=M*tau*log(1+4*exp(v/tau))` — SW бесплатных товаров с нулевыми издержками.
Обе величины являются верхними границами полной SW при неотрицательных издержках.
В этом диапазоне увеличение SW всегда улучшает её компонент награды.
Штрафы являются переводами и сами по себе SW не увеличивают.
Рост благосостояния возможен через реакцию и обучение рыночных участников.

Агенты видят факт **своего** предыдущего штрафа. Без этого признака штраф 25
часто исчезал при дискретизации прибыли. Никакого заданного правила изменения
цены после штрафа нет. Все четыре агента и коалиционный уровень продолжают
обучаться на собственной финансовой награде. Формат таблиц версии 1 читается:
старые состояния дополняются нулевым признаком штрафа без потери значений.

## Все веса этапов

В каждом обучающем запуске создаётся `weights/index.json` с seed, этапом,
параметрами, метриками и SHA-256 файлов:

- `predictor_*/epoch_000.json` — начальные веса до первого обновления;
- `predictor_*/epoch_NNN.json` — веса после каждой эпохи, пригодные для исполнения;
- `predictor_*/epoch_NNN.pt` — те же веса, Adam и состояние перемешивания данных;
- `predictor_round1/` — каждое состояние повторного обучения;
- `development_*/market_before.json`, `market_after.json` — все четыре агента
  и коалиционная политика до/после каждого этапа адаптации;
- `test_*/` — обе ветви независимого сравнения, включая вариант без арбитра.

Арбитр каждого этапа также сохраняется рядом с рыночными весами.
Финальные `arbiter.json` и `market_N.json` не заменяют промежуточные файлы.
В JSON рыночных таблиц сохраняются генераторы случайных чисел.
`train.npz` и `validation.npz` фиксируют признаки и обучающие метки.
Неудачные варианты и их результаты сохраняются для сравнения.

## Использование

```bash
python3 -m market_rl.train --load runs/check/agents.json \
  --arbiter runs/my_validation/arbiter.json \
  --episodes 100 --output runs/agents_adapted
```

```python
from market_rl import LearnedArbiter
from market_rl.agents import load_agents, load_auxiliary
from market_rl.train import evaluate

config, agents = load_agents("runs/check/agents.json")
coalition, _ = load_auxiliary("runs/check/agents.json")
arbiter = LearnedArbiter.load("runs/my_validation/arbiter.json", config)
metrics = evaluate(config, agents, coalition, arbiter=arbiter)
```

`report.json` содержит точность санкций, их количество, пропуски, контроль
на независимых продавцах и парную разницу чистого благосостояния с 95% интервалом.
Интервал учитывает независимые запуски адаптации и целые проверочные эпизоды;
отдельные раунды не считаются независимыми наблюдениями.
Высокая точность штрафов сама по себе не считается доказательством роста SW.
В новых отчётах `qualification.positive_welfare_interval` отмечает положительную
нижнюю границу интервала, а `sanction_precision_passed` — достижение выбранного
порога точности. В проведённых сериях рост SW пока не подтверждён.

## Упрощение предыдущего арбитра

Из рабочего кода исключены PPO/critic, GRU, отдельный pair-encoder и эталон
ценового квантиля. Предыдущий PPO после восьми обновлений выбирал наблюдение,
а его жёсткий квантильный фильтр на сетке 2–12 мог запрещать все санкции.
В проведённой абляции лаги улучшили предсказание, поэтому память цен сохранена.
Это не утверждение о бесполезности GRU вообще: сравнения доведённых до сходимости
PPO и MLP здесь нет.

Исходная адаптация, её тесты и инструкция сохранены в
`runs/arbiter_v2_native/legacy_implementation.zip`, начальные и обученные PPO-веса
также сохранены. Внешний репозиторий `sma_itmo/arbiter_v2` не изменён.
Прежние `.pt` не интерпретируются как веса новой архитектуры.

Дополнительная модель краткосрочного эффекта штрафа не научилась надёжно
выбирать полезные вмешательства. Штрафы как доля выручки также не прошли
проверку на точность и благосостояние. Эти ветви исключены из рабочего арбитра.
Их исходники, тесты и прежняя реализация сохранены в
`runs/experimental_arbiter_archive/implementation.zip`, веса — в исходных
каталогах `runs/logit_effect/` и `runs/logit_fiscal/`.
Обычные checkpoint продолжают загружаться; экспериментальные модели
с активной дополнительной головой или долей выручки требуют архивной реализации.

Методика опирается на идеи учёта реакции обучающихся агентов из
[Learning to Incentivize Other Learning Agents](https://proceedings.neurips.cc/paper_files/paper/2020/file/ad7ed5d47b9baceb12045a929e7e2f66-Paper.pdf)
и [AI Economist](https://arxiv.org/abs/2108.02755).
Оценка неопределённости следует принципам
[Deep RL at the Edge of the Statistical Precipice](https://arxiv.org/abs/2108.13264).
Это применение идей к нашей модели, не воспроизведение алгоритмов этих статей.
